 Cats vs Dogs Classification (Reduced Dataset)

A CNN model to classify cats and dogs images using a reduced dataset of 500 images (250 per class).  
The project demonstrates that CNNs require sufficient data to generalize well—accuracy drops significantly with smaller datasets. Dropout is used to slightly improve generalization, but data quantity has the biggest impact.

 Key Points
- Dataset: 250 cats + 250 dogs
- CNN with Dropout layers
- Training on a small dataset reduces accuracy
- Highlights importance of data size over regularization alone
